# 🍊 橘子便利商店 3D (Gamania Mart 3D) - 經典模擬經營

致敬**遊戲橘子經典《便利商店》**系列！採用 **Three.js**、**日系 Q 版可愛動畫人偶**、**A* 走道導航尋路** 與 **純滑鼠微縮模型風格 (Cozy Diorama)** 打造的經典休閒經營模擬遊戲。

---

## 🌟 遊戲核心特色

### 1. 🎨 自由裝潢與商品擺設系統 (Free Decor & Placement)
- **滑鼠直接拖曳擺設**：點擊「裝潢擺設」，按住店內任意貨架、桌椅、盆栽、ATM、雜誌架或扭蛋機即可直接在地面拖曳移動。
- **全息透化虛影預覽 (Hologram Ghost Preview)**：拖曳移動時呈現**半透明天藍全息虛影**與地面範圍框，並具備 $0.3\text{ m}$ 網格吸附。
- **即時放置合法性檢驗**：若位置擋住大門出入口或收銀台後台，虛影即時轉為**警戒紅色**，防止無效擺放。
- **自由調整陳列商品**：隨時將貨架調整為陳列御飯糰、日式極品綠茶、海鹽洋芋片、泡麵、咖啡或關東煮。
- **主題色彩風格更換**：典雅原木、極簡純白、薄荷清爽、橘子活力、曜石深黑 5 種外觀。
- **促銷立牌標籤**：支援掛上「🔥 超人氣 / 🎉 特價 / ⭐ 店長推薦」立牌。
- **裝潢精品商城**：可添購雙面中島架、雙門飲料冰櫃、關東煮熟食台、室內發光盆栽、開運金光招財貓、雜誌架、雙層扭蛋機、24H ATM 與休閒原木桌椅。

### 2. 🧭 智慧走道導航與 A* 尋路系統 (A* Navigation Grid)
- **$0.4\text{ m}$ 高精度尋路網格**：顧客與小偷在店內嚴格依照走道路線前進，**絕不穿透貨架、桌椅、櫃檯、裝飾物或外牆**。
- **防削角檢驗與視線平滑化**：8 方向 A* 搜尋並平滑化路徑，人物轉身與漫步自然流暢。
- **即時動態烘焙**：玩家移動或新增/撤除貨架擺設時，系統自動重新烘焙網格，顧客立即改走新動線。

### 3. 👥 精緻 Q 版日系微縮人物 (Chibi Characters)
- 豐富角色庫（高中生、上班族、小資女、大學生、常客阿伯、外送員、蒙面小偷）搭配多樣髮型、服飾與配件。
- 專屬 Q 版程序行走彈跳、四肢鐘擺擺動、地面微接觸陰影與心情對話氣泡。
- **購物細節體驗**：顧客提著紅色小購物籃挑選商品，結帳後換成橘子超商專屬環保提袋。

### 4. 🏪 遊戲橘子《便利商店》經典經營機制
- **進貨與毛利率策略**：各類商品進價、售價、庫存容量與毛利率即時計算。
- **定價與顧客滿意度**：定價平易近人吸引大量採購，定價過高顧客會冒出「❓」抱怨並放棄購買。
- **一鍵補滿 (Restock All)**：純滑鼠一鍵自動補齊全店所有貨架缺貨！
- **行銷宣傳活動**：派發社區宣傳單、舉辦買一送一特賣會。
- **突發事件：抓小偷**：小偷溜進店內偷竊時，用**滑鼠點擊小偷**即可將其逮捕，並獲得警民合作獎金 NT$ 300！
- **內用座位享用**：顧客結帳後有機會至店內原木桌椅入座享用美食，滿意度愛心大爆發！
- **打烊營業結算報表**：每日 22:00 自動打烊結算營收、成本、純利、客流量與 S/A/B 經營綜合評鑑。

### 5. 🖱️ 100% 全滑鼠直覺操作
- **滑鼠左鍵/右鍵拖曳**：平移微縮店鋪視角。
- **滑鼠滾輪**：縮放微縮盒景視角大小。
- **點擊紙箱**：快速將進貨紙箱補入指定貨架。
- **點擊貨架**：快速查看庫存並瞬間補滿。
- **點擊顧客**：顧客分享熱情心聲並掉落小費金幣！

## 🚀 本地啟動與開發

```bash
cd convenience-store-3d
npm install
npm run dev
```

開啟瀏覽器前往：`http://localhost:5173/` 即可立即開始營運！
